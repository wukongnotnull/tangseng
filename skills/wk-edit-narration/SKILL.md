# 口播音频剪辑

1. 确定本轮输入和剪辑范围。用户只要求去重时，保留与重读无关的停顿。用户要求在去重版上调节节奏时，从该版重新定位时间点。保留原录音和已有版本，指定了输出位置或格式就按要求交付。
2. 从用户给出的时间点开始核对。需要自行定位时，先用带时间戳的全段转写梳理口播顺序，可对照用户提供的口播稿辨认句子、专名和段落。转写可能把相邻的重读合在一起，也可能漏掉没读完的半句。遇到疑点时，结合波形和静音区间截取短片段，复听或独立转写，并把片段内时间换算回本轮输入的时间轴。需要命令示例时查阅[本地定位与导出](references/local-workflow.md)。
3. 每处重读保留最后一次完整朗读。逐处标出删除区间，从上一句应保留内容的末尾之后开始，到保留版本的首音节之前结束。开头就在重读时，删除区间可从零开始。切口尽量落在安静处，给字头、字尾和换气留余量。根据语义辨认有意强调、隔段复现和独有内容。最后一次仍未读完时，保留可用的完整版本。证据不足的区间先保留，并标出待确认时间点。
4. 用户要求缩短停顿时，先区分句间停顿、换气和段落转换。优先处理明显过长的空档，只从其中已确认的安静区间删减。停顿里有呼吸时，可分别缩短呼吸前后的静音。段落转换通常比句间留得稍长。可安全删除的静音不足时，保留较长的停顿。
5. 将确认后的删除区间按本轮输入的时间轴排序，检查重叠、越界和保留段。对多处切口可用随附的[剪接脚本](scripts/render_cuts.py)一次渲染。它在 PCM WAV 上按采样帧定位，只在内部接缝两侧添加短淡化。可同时做去重和节奏调整时，尽量从无损中间文件导出，最后按目标格式编码一次。
6. 核对成品可以从头到尾解码，剪辑后的时长与计划相符。优先复核容易吞字的接缝、段落过渡和最后一句。可以试听时复听关键片段，也可用二次转写与波形辅助核对，按实际执行的核验方式报告。定位或导出能力有限时，交付已确认的时间表并说明待核验部分。

按用户指定的位置另存文件。可访问素材所在目录时，默认在旁边保存带「去重剪辑」或「节奏优化」后缀的新版本。交付可打开的音频链接、编辑数量、成品时长和仍需复核的时间点。
