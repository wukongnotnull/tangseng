# 中文句式辨析

## 先辨作用，再选助词

| 例句 | 判断依据 |
| --- | --- |
| 她交来一份详细的说明。 | “详细”修饰名词“说明”，作定语。 |
| 她详细地说明了原因。 | “详细”修饰动词“说明”，作状语。“她详细说明了原因”也成立。 |
| 她把原因说得很清楚。 | “很清楚”在“说”后作补语，说明说得怎么样。 |
| 这份说明清楚极了。 | “清楚”是形容词，“极了”在后面补充程度。 |
| 我累得不想动。 | “累”是形容词，“得”引出补语“不想动”，用具体表现写出累的程度。 |
| 得先看懂这张图。 | “得先”中的“得”读 děi，表示需要；“懂”是“看”的结果补语。 |

动词后还可出现趋向和数量补语，如“走进来”“试了三遍”。避免按词所在的位置硬贴标签。“跑得快”和“跑得动”形式相近，前者可以描述速度，后者表示有能力跑。

## 用原意检验改法

| 草稿或句式 | 校对时怎么处理 |
| --- | --- |
| 新版本提高了速度和耗时。 | 若原意是运行更快，可写“新版本提高了运行速度，缩短了耗时”。先确定原意，再给并列项分别选择动词。 |
| 通过这次练习，使学生掌握了语序。 | 独立成句时可删去“使”，写成“通过这次练习，学生掌握了语序”。若上文已有明确主语，则结合上下文判断。 |
| 新版的启动时间比旧版更短。 | 日常表达中，“旧版”可以承接“旧版的启动时间”。若上下文里有多个指标，可改为“与旧版相比，新版的启动时间更短”。 |
| 只要审核通过，用户才可以发布。 | 若审核通过是必要条件，写“只有审核通过，用户才可以发布”；若审核通过就足以发布，写“只要审核通过，用户就可以发布”。 |
| 明天不会开会。／昨天没开会。／我以前不喝咖啡。 | “不”可表示意愿、判断或习惯，“没”可否定事件的发生。“以前”也能与“不”连用。 |
| 任务完成了。／门开着。／我去过南京。 | 分别关注完成或状态变化、状态持续、曾有的经历。“如果明天下了雨，就改期”说明“了”也能出现在假设的未来情境里。 |

## 按句式核对角色

- **把字句、被字句**。“我把草稿发给了编辑”和“草稿被退回了”都要交代动作落在什么对象上。被字句的主语可以是受事，施事可以省略。
- **形容词谓语、存现句**。“今天很冷”可以直接用形容词作谓语。“门口来了两位老师”先交代地点，再引出新出现的人。保留自然的量词和语序。
- **连动句、兼语句**。“我去书店买词典”中，两个动作的施事都是“我”。“老师让我举例”中，“我”既是“让”的宾语，也是“举例”的施事。
- **比较句、疑问句**。“比上周快了两秒”说明差量，“和上周一样快”说明相等。直接提问可说“要不要保存？”；“你知道要不要保存吗？”中，“吗”作用于外层问句，不能一看到“要不要……吗”就删字。
- **省略和口播**。“试过了，挺好用的。”在回答“这个功能你试过吗”时意思完整。保留停顿、短句与省略，只在读者无法判断动作主体或指代对象时补足。
