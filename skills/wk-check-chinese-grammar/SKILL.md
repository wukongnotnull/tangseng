# 中文语法检查

## 先确定交付内容

- **日常回答**：先解决用户的问题，再默读自己的中文草稿，直接交付校正后的答案。无需提醒用户使用了技能，也无需点评用户提问的措辞。
- **明确要求校对**：遵循用户指定的范围和格式。只要改稿时，直接给改稿。要求解释时，摘出有问题的原文，给出最小改法，并指出是错别字还是语病。没有发现指定范围内的问题就如实说明。把语体或节奏方面的可选建议与实际错误区分开。
- **要求讲语法**：用与问题对应的例句解释。分析句子时点明具体词语的作用；若存在几种合理的语法分析，只解释回答该问题所需的部分。

## 检查错别字

- 结合句意、固定搭配和成语，检查同音或近音误写、形近字混淆，以及输入时漏写、多写或写反的字。比如，“再次确人”应为“再次确认”，“按步就班”应为“按部就班”。
- 根据上下文判断用字。“再提交一次”表示重复，“正在提交”描述正在发生的动作，两处用字都正确。保留有意使用的方言、简繁写法和双关。
- 核对人名、地名和专业术语时，以用户提供的权威写法或文中可核实的依据为准。依据不足时保留原字。用户明确要求校对时，可以标注疑点供确认。逐字引文、代码、命令、链接、标识符和界面标签按原样保留。

## 默读时怎么判断

1. **看句子说的是谁、说了什么。** 找出话题和谓语中心，逐一核对主谓、动宾及并列搭配。遇到长定语，可先略去修饰语，读一遍主干，再检查修饰范围。根据上下文判断省略是否自然；“明天见”“这本书，我读过”都可以直接使用。
2. **看前后的修饰关系。** 区分名词前的定语、动词或形容词前的状语，以及动词或形容词后的补语。需要结构助词时，再选择“的、地、得”。“认真检查”和“认真地检查”都成立。“急得直跺脚”中，“得”引出补语“直跺脚”；“冷极了”同样有补语，无须加“得”。
3. **看句式与所述事件是否相符。** 使用“把”或“被”时，核对谁实施动作、谁受到影响，结果归于谁。核对“了、着、过”表示的完成、变化、持续或经历，以及“不、没（有）”的否定范围。按语境判断，不能看到时间词就机械增删助词。
4. **看分句能否接起来。** 确认因果、条件、转折、递进等关系符合原意，动作主体转换时指代仍然清楚。尤其要保留“只要……就……”和“只有……才……”的区别。比较两个对象时，核对比较的是同一属性。
5. **改后回读。** 优先改动有问题的词或分句。保留事实、数量、限定词、肯否、语气和用户指定的文体。若原文有两种会改变结论的解读，结合上下文判断；仍无法判断时，给出对应改法或只问一个具体问题。按原样保留逐字引文、代码、命令、链接、标识符和界面标签，只校正外围说明。

遇到补语、特殊句式或关联词难以判定，或需要向用户讲解时，查阅[中文句式辨析](references/sentence-patterns.md)。
